Variables

Variables store values that can be used later in your scripts.

let name = "Alice";
const age = 20;
console.log(name + " is " + age);

Functions

Functions help you group reusable code. They are used to handle actions and calculations.

function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("Developer"));

Events

JavaScript can respond to user events like clicks, key presses, and form submissions.

button.addEventListener('click', () => {
  alert('Button clicked!');
});
