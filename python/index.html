Variables

A variable is a container used to store data such as numbers, text, or lists.

name = "Alice"
age = 21
print(name, age)

Loops

A loop repeats instructions until a condition is met. This is useful for processing lists and repeated tasks.

for i in range(3):
    print("Learning Python")

Functions

Functions help you write reusable code for repeated tasks.

def greet(name):
    return f"Hello, {name}!"

print(greet("Developer"))
