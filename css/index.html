Selectors

Selectors target HTML elements so CSS can style exactly the parts you want.

h1 { color: blue; }
p { font-size: 16px; }

Flexbox

Flexbox helps you align content in rows and columns with less manual positioning.

.row {
  display: flex;
  justify-content: space-between;
}

Media queries

Media queries let your design respond to different screen sizes and devices.

@media (max-width: 768px) {
  .row { flex-direction: column; }
}
