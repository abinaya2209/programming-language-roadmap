Variables

Variables store values in memory so your program can reuse them during execution.

int age = 21;
char grade = 'A';
printf("Age: %d\n", age);

Pointers

Pointers help C programs access memory directly, which is powerful but must be handled carefully.

int number = 10;
int *ptr = &number;
printf("%d\n", *ptr);

Functions

Functions help organize code into reusable blocks that are easier to maintain.

int add(int a, int b) {
    return a + b;
}

printf("%d\n", add(5, 3));
