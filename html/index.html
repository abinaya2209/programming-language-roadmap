HTML elements

HTML elements define the structure of a webpage such as headings, paragraphs, links, and buttons.

<h1>Hello World</h1>
<p>This is a paragraph.</p>
<button>Click me</button>

Forms

Forms collect user input so people can submit data such as names, email addresses, or search terms.

<form>
  <input type="text" name="name">
  <button>Submit</button>
</form>

Semantic tags

Semantic tags describe the meaning of a page section, which improves both accessibility and maintainability.

<header>...</header>
<main>...</main>
<footer>...</footer>
